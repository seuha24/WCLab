# SafeLight 시각장애인 미팅 자료

## 프로젝트 소개
SafeLight는 시각장애인의 안전한 보행을 지원하는 모바일 애플리케이션입니다.  
"오늘도 걷는 당신을 위한 등대"라는 슬로건으로 일상 보행의 어려움을 해결합니다.

---

## 핵심 기능 리스트

### 1. 🚦 BLE 스마트 횡단보도 제어
**목적**: 횡단보도의 음향신호기를 스마트폰으로 제어
- **자동 스캔**: 20초마다 주변 횡단보도 자동 검색
- **수동 검색**: 버튼 탭으로 즉시 주변 검색
- **안전 리모컨**: 
  - 음성 유도: 횡단보도 위치를 음성으로 안내
  - 압버튼 누르기: 물리적 버튼 없이 신호 변경
- **피드백 제공 시점**: 횡단보도 감지 시 즉시 알림

### 2. 🧭 경로 안내 시스템  
**목적**: 목적지까지 정확하고 안전한 경로 제공
- **경로 옵션**: 
  - 추천 경로
  - 최단 거리
  - 계단 제외 경로
- **실시간 음성 안내**: 
  - 방향 전환 지점 15m 전 사전 안내
  - 시계 방향 안내 (예: "3시 방향으로 가세요")
  - 횡단보도 접근 시 "차량에 유의하세요" 경고
- **경로 이탈 감지**: 15m 이상 벗어나면 자동 재검색
- **경유지 지원**: 최대 5개까지 설정 가능

### 3. 💡 안전 경광등
**목적**: 야간이나 악천후 시 보행자 위치를 운전자에게 알림
- **자동 작동 조건**:
  - 야간 시간 (일몰 후 ~ 일출 전)
  - 비/눈/안개 등 악천후
  - 주변이 어두울 때 (조도 센서 감지)
- **점멸 패턴**: 2초 주기 (1초 켜짐, 1초 꺼짐)
- **모드 설정**:
  - 항상 켜기
  - 날씨에 따라 자동
  - 항상 끄기

### 4. 🗣️ TTS 음성 안내
**목적**: 모든 중요 정보를 음성으로 전달
- **안내 상황**:
  - 경로 안내 (방향 전환, 거리)
  - 횡단보도 발견 알림
  - 경계 이탈 경고
  - 시스템 상태 변경
- **최적화된 재생 속도**: 
  - iOS: 1.2배속
  - Android: 1.6배속
- **설정 가능**: ON/OFF 토글

### 5. ⭐ 즐겨찾기 시스템
**목적**: 자주 가는 장소와 경로를 빠르게 접근
- **지점 즐겨찾기**: 집, 회사, 학교 등 자주 가는 장소 저장
- **경로 즐겨찾기**: 출퇴근, 등하교 등 반복 경로 저장
- **서버 동기화**: 기기 변경 시에도 데이터 유지
- **출입구 정보 포함**: 정확한 건물 출입구로 안내

### 6. 📍 IMU 위치추적
**목적**: GPS 신호가 약한 실내나 지하에서도 위치 추적
- **자동 전환**: GPS 정확도 15m 이하일 때 IMU 모드 활성화
- **센서 융합**: 가속도계, 자이로스코프, 나침반 통합
- **정확한 방향 안내**: 나침반 기반 시계 방향 음성 안내
- **경로 정렬 피드백**: 올바른 방향일 때 진동 (200ms)

### 7. 🏢 출입구 등록 및 조회
**목적**: 건물의 정확한 출입구 위치 정보 제공
- **커뮤니티 기반**: 사용자들이 직접 등록한 출입구 정보 공유
- **간편한 등록**: 지도에서 위치 선택 후 이름만 입력
- **자동 연동**: 경로 탐색 시 등록된 출입구로 자동 안내
- **다중 출입구 지원**: 정문, 후문, 장애인 출입구 구분

### 8. 🔐 로그인 및 사용자 관리
**목적**: 개인화된 서비스 제공 및 데이터 동기화
- **간편 로그인**: 구글, 애플 소셜 로그인
- **익명 사용**: 로그인 없이도 기본 기능 사용 가능
- **데이터 백업**: 즐겨찾기, 설정 자동 백업

### 9. ⚙️ 설정 관리
**목적**: 사용자 맞춤 환경 설정
- **권한 관리**: 블루투스, 위치 권한 설정
- **테마 설정**: 다크모드, 라이트모드, 시스템 모드
- **기능 설정**: 경광등 모드, TTS ON/OFF
- **접근성 최적화**: 큰 글씨, 고대비 지원

### 10. 📚 튜토리얼 및 도움말
**목적**: 앱 사용법 학습 지원
- **5단계 튜토리얼**: 주요 기능별 상세 설명
- **체험 기능**: 안전 나침반 실제 체험 가능 (iOS)
- **언제든 재확인**: 설정 → 도움말에서 다시 볼 수 있음

## 특별 기능 상세

### 🧭 안전 나침반 (iOS 전용)
- 점자블록이 없는 횡단보도에서 방향 안내
- 진동으로 올바른 방향 알림
- 잘못된 방향 진행 시 음성 경고

### 🚨 횡단보도 접근 시 통합 동작
1. 경로 안내 중 횡단보도 15m 전 음성 알림
2. 안전 경광등 자동 작동 (설정에 따라)
3. BLE 압버튼 자동 검색
4. 안전 나침반 활성화 (iOS)

## 피드백 받고 싶은 부분

### 1. 사용성 관련
- 음성 안내 속도와 내용이 적절한지
- 버튼 크기와 배치가 사용하기 편한지
- 진동 피드백 강도가 적절한지

### 2. 기능 우선순위
- 가장 유용한 기능은 무엇인지
- 불필요하거나 개선이 필요한 기능
- 추가로 필요한 기능이 있는지

### 3. 안전성
- 경로 이탈 감지 거리 (현재 15m)가 적절한지
- 횡단보도 사전 안내 거리 (15m)가 적절한지
- 경광등 점멸 패턴이 효과적인지

### 4. 접근성
- VoiceOver/TalkBack과의 호환성
- 추가로 필요한 접근성 기능
- 현재 UI가 시각장애인 친화적인지
