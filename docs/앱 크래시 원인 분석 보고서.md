# SafeLight 앱 크래시 원인 분석 보고서

## 📋 분석 요약
경로 안내 기능 사용 시 발생하는 앱 크래시는 **메모리 누수**와 **과도한 렌더링 부하**가 주요 원인입니다.

## 🔴 치명적 문제 (Critical Issues)

### 1. Timer 메모리 누수 ⚠️ 
**파일**: `lib/presentation/controllers/map_view_controller.dart`  
**위치**: 387-390번 줄

```dart
// 현재 코드 (문제)
Timer.periodic(Duration(milliseconds: 100), (timer) {
  s_accuracy = position.accuracy;
  _getLocation();
});
```

**문제점**:
- Timer가 변수에 할당되지 않아 **취소 불가능**
- 100ms마다 GPS 위치를 조회 (초당 10번)
- 앱이 종료될 때까지 계속 실행됨
- 경로 안내를 여러 번 시작하면 **Timer가 중복 생성**되어 메모리 사용량 기하급수적 증가

**영향도**: ⭐⭐⭐⭐⭐ (매우 높음)

---

### 2. 마커 이미지 메모리 누적 🖼️
**파일**: `lib/presentation/controllers/map_view_controller.dart`  
**위치**: 
- 1165-1175번 줄 (updateCurrentLocationMarker)
- 611-633번 줄 (addBranchMarkers)

```dart
// 매번 새로운 이미지 생성 (문제)
final iconImage = await NOverlayImage.fromWidget(
  widget: Transform.rotate(
    angle: adjustedAngle * (math.pi / 180),
    child: Icon(icon, color: markerColor, size: 25),
  ),
  size: const Size(25, 25),
  context: navigatorKey.currentContext!
);
```

**문제점**:
- 마커 업데이트 시마다 **새로운 이미지 객체 생성**
- 100ms마다 호출되면 초당 10개의 이미지 메모리 누적
- 이전 이미지가 가비지 컬렉션되지 않음
- 특히 경로 안내 시작/종료 시 다량의 마커 생성/제거

**영향도**: ⭐⭐⭐⭐ (높음)

---

### 3. 과도한 렌더링 부하 🔄
**로그 증상**:
```
E/FrameEvents(7410): updateAcquireFence: Did not find frame
```

**관련 코드**:
- `_getLocation()` - 100ms마다 호출
- `updateCurrentLocationMarker()` - 위치 업데이트마다 호출
- `updateMapByMode()` - 지도 업데이트

**문제점**:
- 초당 10번의 지도 업데이트 시도
- 프레임 드롭 발생 (60fps 유지 불가)
- GPU/CPU 과부하로 인한 ANR(Application Not Responding)

**영향도**: ⭐⭐⭐ (중간)

## 📊 메모리 사용 패턴 분석

### 시나리오별 메모리 증가량 추정

| 시나리오 | 메모리 증가 | 원인 |
|---------|------------|------|
| 앱 실행 후 대기 | 100MB/분 | Timer 누수 |
| 경로 안내 시작 | +50MB | 마커 이미지 생성 |
| 경로 안내 10분 | +1GB | Timer + 이미지 누적 |
| 경로 안내 종료 | 감소 없음 | Timer 계속 실행 |

## 🔧 해결 방안

### 우선순위 1: Timer 관리
```dart
// 수정안
class NaverMapViewController extends GetxController {
  Timer? _locationTimer; // Timer 변수 추가
  
  void _initLocation(Position position) async {
    // ...
    _locationTimer?.cancel(); // 기존 타이머 취소
    _locationTimer = Timer.periodic(Duration(seconds: 1), (timer) { // 1초로 변경
      s_accuracy = position.accuracy;
      _getLocation();
    });
  }
  
  @override
  void onClose() {
    _locationTimer?.cancel(); // 컨트롤러 종료 시 취소
    _locationUpdateTimer?.cancel();
    navigationTimer?.cancel();
    // ...
  }
}
```

### 우선순위 2: 이미지 캐싱
```dart
// 마커 이미지 사전 생성 및 재사용
class NaverMapViewController extends GetxController {

  void onInit() {
    super.onInit();
    _initMarkerImages();
  }
  
  Future<void> _initMarkerImages() async {
    blueMarkerImage = await NOverlayImage.fromWidget(...);
    redMarkerImage = await NOverlayImage.fromWidget(...);
  }
}
```

### 우선순위 3: 업데이트 주기 최적화
- GPS 업데이트: 100ms → 1000ms
- 네비게이션 체크: 2초 유지 (적절함)
