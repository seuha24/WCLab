# 경광등 기능 명세서

## 개요
SafeLight 애플리케이션의 안전 경광등 기능은 시야가 확보되지 않는 상황에서 보행자의 위치를 운전자에게 알려주는 핵심 안전 기능입니다. 스마트폰의 카메라 플래시를 주기적으로 점멸시켜 경광등 효과를 구현합니다.

## 주요 기능

### 1. 경광등 작동 방식
- **점멸 패턴**: 2초 주기로 1초 켜짐, 1초 꺼짐 반복
- **무한 모드**: 사용자가 수동으로 끌 때까지 계속 작동
- **제한 모드**: 설정된 횟수(기본 30회)만큼 점멸 후 자동 종료
- **알림**: 무한 모드에서 30초마다 TTS로 "현재 경광등이 켜져 있습니다" 알림

### 2. 경광등 모드 설정

#### 2.1 FlashMode 열거형
```dart
enum FlashMode {
  WITH_WEATHER,    // 날씨/조도에 따라 자동
  ALWAYS,          // 항상 켜기
  NEVER_IN_USE     // 항상 끄기
}
```

#### 2.2 모드별 동작
- **항상 켜기 모드 (ALWAYS)**: 조건 없이 경광등 즉시 작동
- **날씨 기반 모드 (WITH_WEATHER)**: 환경 조건 판단 후 자동 작동
- **항상 끄기 모드 (NEVER_IN_USE)**: 경광등 기능 비활성화

### 3. 날씨 기반 자동 작동 조건

#### 3.1 작동 트리거 조건 (하나라도 만족 시 작동)
- **야간**: 일몰 후 ~ 일출 전
- **시야 불량**: visibility < 500m
- **악천후**: 
  - 비/눈/안개 (weather ID: 200-622)
  - 짙은 구름 (weather ID: 804)
- **조도 부족**: 조도 센서 값 ≤ 1.2

#### 3.2 조도 측정
- 전면 카메라 센서 활용
- 렌즈 조리개, 노출 시간, 센서 감도를 이용한 주변 밝기 계산
- 계산식: `ambientLightLevel = ((50 * lensAperture²) / (sensorExposureTime * sensorSensitivity)) * 100000000`

## 시스템 아키텍처

### 1. 계층 구조
```
Presentation Layer (View)
    ↓
Domain Layer (UseCase)
    ↓
Data Layer (Repository)
    ↓
Data Source Layer
```

### 2. 주요 컴포넌트

#### 2.1 Presentation Layer
- **FlashlightView**: 경광등 전용 화면 UI
  - 켜기/끄기 버튼 제공
  - TTS 및 스낵바 피드백
- **HomeView**: 홈 화면에서 경광등 접근
  - iOS 전용 경광등 버튼 제공
- **SettingView**: 경광등 모드 설정
  - 3가지 모드 선택 UI

#### 2.2 Domain Layer
- **ControlFlash** (인터페이스)
  - 모든 경광등 UseCase의 부모 인터페이스
- **ControlFlashOn**: 수동 경광등 켜기
- **ControlFlashOff**: 경광등 끄기
- **ControlFlashOnWithWeather**: 날씨 기반 자동 켜기

#### 2.3 Data Layer
- **FlashRepository** (인터페이스)
  - `turnOn()`: 경광등 켜기
  - `turnOff()`: 경광등 끄기
  - `turnOnWithWeather()`: 날씨 기반 켜기
- **FlashRepositoryImpl**: Repository 구현체

#### 2.4 Data Source Layer
- **FlashNativeDataSource**: 플래시 하드웨어 제어
  - TorchLight 라이브러리 활용
  - Timer 기반 점멸 제어
- **AmbientLightLevelDataSource**: 조도 센서 데이터
- **WeatherRemoteDataSource**: 날씨 API 연동
- **NavigateRemoteDataSource**: 현재 위치 정보

### 3. 검증 로직
- **WeatherValidator**: 경광등 작동 여부 판단
  - FlashMode 설정 확인
  - 날씨/조도 조건 검증
  - boolean 결과 반환

## 사용자 경험

### 1. 접근 경로
- 홈 화면 우측 상단 경광등 버튼 (iOS 전용)
- 설정 화면에서 모드 변경
- 안전 리모콘 음성 유도 시 자동 작동
- 압버튼 누르기 시 자동 작동

### 2. 피드백
- **시각적**: 플래시 점멸
- **청각적**: TTS 음성 안내
  - "안전 경광등이 켜졌습니다"
  - "안전 경광등이 꺼졌습니다"
  - "안전 경광등을 사용할 수 없습니다"
- **촉각적**: 스낵바 메시지

### 3. 에러 처리
- 플래시 하드웨어 미지원 시 안내
- 카메라 권한 필요 시 요청
- 위치 권한 필요 시 요청 (날씨 모드)

## 관련 API

### Open Weather API
- 엔드포인트: https://openweathermap.org/api
- 용도: 현재 위치의 날씨 정보 조회
- 데이터: 시야거리, 날씨 ID, 일출/일몰 시각

### TorchLight 라이브러리
- 패키지: torch_light
- 기능: 플래시 하드웨어 직접 제어
- 메서드:
  - `isTorchAvailable()`: 플래시 지원 확인
  - `enableTorch()`: 플래시 켜기
  - `disableTorch()`: 플래시 끄기

## 문제 해결 가이드

### 경광등이 작동하지 않을 때
1. 설정에서 모드 확인 (항상 끄기 모드 아닌지)
2. 카메라 권한 허용 확인
3. 플래시 하드웨어 정상 여부 확인

### 날씨 모드가 작동하지 않을 때
1. 위치 권한 허용 확인
2. 인터넷 연결 상태 확인
3. 설정에서 WITH_WEATHER 모드 선택 확인

### 배터리 소모가 심할 때
1. 무한 모드 대신 제한 모드 사용
2. 설정에서 항상 끄기 모드로 변경
3. 불필요한 경광등 사용 자제
