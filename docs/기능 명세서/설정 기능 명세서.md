# 설정 기능 명세서

## 개요
SafeLight 애플리케이션의 설정 시스템은 사용자가 앱의 동작과 인터페이스를 개인화할 수 있는 다양한 옵션을 제공합니다. 사용자 정보 관리, 권한 설정, 테마 설정, 경광등 모드 설정, 음성 안내 설정 등 핵심 기능들을 중앙에서 관리합니다.

## 주요 설정 항목

### 1. 사용자 정보 관리

#### 1.1 사용자 정보 표시
- **현재 로그인 사용자명 표시**
- **로그아웃 버튼**
- **사용자 아이콘 표시**

#### 1.2 로그아웃 기능
- 로그아웃 아이콘 탭 시 실행
- AuthBloc의 SignOutAllEvent 호출
- AuthService를 통한 로컬 인증 데이터 삭제
- 로그인 화면(SignInView)으로 이동

### 2. 앱 내 권한 설정

#### 2.1 블루투스 권한
- **용도**: BLE 스마트 압버튼 검색 및 연결
- **UI**: CupertinoSwitch 토글
- **상태 관리**: BluetoothPermissionCubit
- **시각적 표시**: 
  - 아이콘: bluetooth (파란색)
  - 활성화/비활성화 상태 토글

#### 2.2 위치 정보 권한
- **용도**: 사용자 현재 위치 파악 및 경로 탐색
- **UI**: CupertinoSwitch 토글
- **상태 관리**: LocationPermissionCubit
- **시각적 표시**:
  - 아이콘: gps_fixed_rounded (빨간색)
  - 활성화/비활성화 상태 토글

### 3. 시스템 모드 설정

#### 3.1 테마 모드
- **선택 옵션**:
  - 시스템 모드: 기기 설정 따름
  - 다크 모드: 어두운 테마
  - 라이트 모드: 밝은 테마

#### 3.2 테마 저장 방식
- **저장소**: Hive 로컬 데이터베이스
- **Box 이름**: 'themeBox'
- **키**: 'mode'
- **값**: system / dark / light

#### 3.3 테마 색상 구성
```dart
ColorScheme light {
  primary: Color(0xff758BFD),      // 보라색
  onPrimary: Color(0xFFFFFFFF),    // 흰색
  secondary: Color(0xFFFFFFFF),    // 흰색
  onSecondary: Color(0xff2A2C41),  // 진한 회색
  background: Color(0xffF1F2F6),   // 연한 회색
  onBackground: Color(0xff939AA3),  // 중간 회색
  surface: Color(0xffEAEAEA),      // 밝은 회색
}

ColorScheme dark {
  primary: Color(0xff758BFD),       // 보라색
  onPrimary: Color(0xFFFFFFFF),     // 흰색
  secondary: Color(0xFF282828),     // 진한 회색
  onSecondary: Color(0xffF1F2F6),   // 연한 회색
  background: Colors.black,         // 검정
  onBackground: Color(0xffEAEAEA),  // 밝은 회색
  surface: Color(0xff121215),       // 매우 진한 회색
}
```

### 4. 경광등 설정

#### 4.1 경광등 모드 (FlashMode)
```dart
enum FlashMode {
  ALWAYS,        // 항상 켜기 모드
  WITH_WEATHER,  // 주변 환경에 따라 켜기 모드
  NEVER_IN_USE,  // 항상 끄기 모드
}
```

#### 4.2 모드별 동작
- **항상 켜기 모드**: 조건 없이 경광등 작동
- **날씨 기반 모드**: 날씨/조도 조건에 따라 자동 작동
- **항상 끄기 모드**: 경광등 기능 비활성화

#### 4.3 저장 방식
- **저장소**: Hive 로컬 데이터베이스
- **Box 이름**: 'flashmode'
- **TypeAdapter**: FlashModeAdapter (typeId: 2)
- **기본값**: FlashMode.ALWAYS

### 5. 음성 보조 설정 (TTS)

#### 5.1 TTS 기능
- **용도**: 횡단보도 검색/연결 시 음성 안내
- **UI**: CupertinoSwitch 토글
- **저장 키**: 'tts'
- **기본값**: false (비활성화)

#### 5.2 TTS 서비스 설정
- **언어**: 한국어 (ko-KR)
- **재생 속도**:
  - Android: 1.6배속
  - iOS: 1.2배속
- **볼륨**: 1.0 (최대)
- **큐 관리**: StreamController를 통한 순차 처리

### 6. 기타 설정

#### 6.1 외부 라이센스
- 오픈소스 라이센스 정보 표시
- Flutter LicensePage 활용

#### 6.2 도움말
- 튜토리얼 화면(TutorialView)으로 이동
- 앱 사용법 안내

## 시스템 아키텍처

### 1. 계층 구조
```
View Layer (SettingView)
    ↓
Cubit/Bloc Layer (State Management)
    ↓
UseCase Layer (Business Logic)
    ↓
Repository Layer
    ↓
Data Source Layer (Hive/SharedPreferences)
```

### 2. 주요 컴포넌트

#### 2.1 View Layer
- **SettingView**: 설정 화면 UI
  - 사용자 정보 섹션
  - 권한 설정 섹션
  - 기타 설정 섹션
  - Modal Bottom Sheet 활용

#### 2.2 State Management

##### Cubit 구조
- **BluetoothPermissionCubit**: 블루투스 권한 상태 관리
  - State: bool (권한 부여 여부)
  - Methods:
    - getPermissionStatus(): 권한 상태 확인
    - setPermissionStatus(): 권한 요청

- **LocationPermissionCubit**: 위치 권한 상태 관리
  - State: bool (권한 부여 여부)
  - Methods:
    - getPermissionStatus(): 권한 상태 확인
    - setPermissionStatus(): 권한 요청

##### Bloc 구조
- **AuthBloc**: 인증 상태 관리
  - GetUserInfoEvent: 사용자 정보 조회
  - SignOutAllEvent: 전체 로그아웃

#### 2.3 UseCase Layer

##### Permission UseCases
- **GetPermission** (인터페이스)
  - GetBluetoothPermission: 블루투스 권한 확인
  - GetLocationPermission: 위치 권한 확인

- **SetPermission** (인터페이스)
  - SetBluetoothPermission: 블루투스 권한 요청
  - SetLocationPermission: 위치 권한 요청

##### Service UseCases
- **ControlFlash** (인터페이스)
  - ControlFlashOn: 경광등 켜기
  - ControlFlashOff: 경광등 끄기
  - ControlFlashOnWithWeather: 날씨 기반 켜기

#### 2.4 Repository Layer
- **PermissionRepository**: 권한 관리
  - getBluetoothPermission()
  - setBluetoothPermission()
  - getLocationPermission()
  - setLocationPermission()

- **FlashRepository**: 경광등 관리
  - turnOn()
  - turnOff()
  - turnOnWithWeather()

#### 2.5 Data Source Layer
- **SettingCacheDataSource**: 설정 캐시 관리 (미구현)
- **Hive Boxes**:
  - themeBox: 테마 설정 저장
  - flashmode: 경광등 모드 저장
  - tts: 음성 안내 설정 저장

## 데이터 저장 구조

### 1. Hive 데이터베이스
- **로컬 NoSQL 데이터베이스**
- **Key-Value 저장 방식**
- **TypeAdapter를 통한 커스텀 타입 지원**

### 2. 저장 데이터
```dart
// 테마 설정
Box('themeBox') {
  'mode': 'system' | 'dark' | 'light'
  'tts': true | false
}

// 경광등 설정
Box<FlashMode>('flashmode') {
  0: FlashMode.ALWAYS | FlashMode.WITH_WEATHER | FlashMode.NEVER_IN_USE
}
```

### 3. SharedPreferences (AuthService)
```dart
// 인증 데이터
{
  'accessToken': String
  'refreshToken': String
  'authTypeToken': 'google' | 'apple' | 'anonymous'
  'userName': String
  'serverUserId': String
}
```

## UI/UX 디자인

### 1. 레이아웃 구조
```
AppBar (사용자 정보)
├── 사용자 아이콘
├── 사용자명
└── 로그아웃 버튼

Body (스크롤 가능)
├── Board: 앱 내 권한
│   ├── 블루투스 권한 토글
│   └── 위치 정보 권한 토글
└── Board: 기타
    ├── 시스템 모드 설정
    ├── 경광등 설정
    ├── 음성 보조 설정
    ├── 외부 라이센스
    └── 도움말
```

### 2. UI 컴포넌트

#### 2.1 Board 위젯
- 설정 그룹을 구분하는 컨테이너
- 타이틀과 바디 영역 구분
- 패딩과 마진 적용

#### 2.2 ListTile
- 각 설정 항목 표시
- leading: 아이콘
- title: 설정 이름
- subtitle: 현재 상태 (선택적)
- trailing: 토글 스위치 또는 화살표

#### 2.3 Modal Bottom Sheet
- 선택지가 많은 설정 항목용
- 높이: 800.h
- 닫기 버튼 포함
- FlatCard로 각 옵션 표시

### 3. 접근성 (Accessibility)

#### 3.1 Semantics 속성
- **버튼 힌트**: 각 설정 항목의 기능 설명
- **체크 상태**: 토글 스위치의 on/off 상태
- **라벨**: 스크린 리더용 설명 텍스트

#### 3.2 접근성 예시
```dart
Semantics.fromProperties(
  properties: SemanticsProperties(
    button: true,
    hint: '앱의 블루투스 사용 허가를 위해 설정이 필요합니다.',
    checked: state,
  ),
  child: ListTile(...)
)
```

## 상태 변경 플로우

### 1. 권한 설정 변경
```
사용자 토글 탭
    ↓
setPermissionStatus() 호출
    ↓
OS 권한 요청 다이얼로그
    ↓
사용자 응답
    ↓
getPermissionStatus() 호출
    ↓
Cubit 상태 업데이트
    ↓
UI 리빌드
```

### 2. 테마 모드 변경
```
모달 시트 열기
    ↓
옵션 선택
    ↓
Hive box.put() 호출
    ↓
setState() 호출
    ↓
모달 닫기
    ↓
UI 업데이트
```

### 3. 경광등 모드 변경
```
모달 시트 열기
    ↓
옵션 선택
    ↓
flashbox.clear() → flashbox.add()
    ↓
setState() 호출
    ↓
모달 닫기
    ↓
UI 업데이트
```

### Android

- Material Design 가이드라인 준수

## 초기화 프로세스

### 1. initState() 실행 순서
1. 권한 상태 확인 (Bluetooth, Location)
2. Hive Box 열기 (themeBox, flashmode)
3. 저장된 설정값 로드
4. 사용자 정보 조회 (GetUserInfoEvent)

### 2. 기본값 설정
- 테마 모드: ThemeMode.system
- 경광등 모드: FlashMode.ALWAYS
- TTS: false (비활성화)
- 권한: false (미부여)

### 1. 권한 요청 실패

### 2. Hive 데이터 읽기 실패
- 기본값으로 폴백

### 3. 사용자 정보 조회 실패

## 문제 해결 가이드

### 설정이 저장되지 않을 때
1. Hive 초기화 확인
2. Box 이름 및 키 확인
3. TypeAdapter 등록 확인

### 권한이 작동하지 않을 때
1. OS 설정에서 권한 상태 확인
2. Info.plist/AndroidManifest.xml 설정 확인
3. Cubit 상태 업데이트 확인

### 테마가 적용되지 않을 때
1. MaterialApp의 themeMode 바인딩 확인
2. Hive box 리스너 동작 확인
3. ColorScheme 정의 확인
