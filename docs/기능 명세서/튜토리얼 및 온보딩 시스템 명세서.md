# 튜토리얼 및 온보딩 시스템 명세서

## 1. 개요
SafeLight 애플리케이션의 튜토리얼 및 온보딩 시스템은 신규 사용자가 앱의 핵심 기능을 이해하고 원활하게 시작할 수 있도록 돕는 교육 및 안내 시스템입니다. 도움말, 사용자 등록, 초기 설정 등 통합적인 사용자 경험을 제공합니다.

## 2. 시스템 구성

### 2.1 주요 구성 요소

#### TutorialView (lib/presentation/views/tutorial_view.dart)
- **역할**: 앱 기능 설명 및 사용법 안내
- **특징**:
  - 5개 페이지로 구성된 스크롤 가능한 튜토리얼
  - 이전/다음 네비게이션 버튼
  - 체험 기능 제공 (안전 나침반)
  - 이미지 포함 상세 설명

#### SignInView (lib/presentation/views/sign_in_view.dart)  
- **역할**: 로그인 및 튜토리얼 진입점
- **특징**:
  - "처음 사용하시나요?" 버튼으로 튜토리얼 접근
  - 소셜 로그인 옵션 제공
  - 익명 로그인 지원
  - Lottie 애니메이션 배경

#### SignupUserInput (lib/presentation/views/signup_user_input.dart)
- **역할**: 신규 사용자 닉네임 설정
- **특징**:
  - 첫 로그인 시 닉네임 입력
  - 사용자 정보 저장
  - 메인 화면 진입 전 필수 단계

#### Native Splash Screen
- **역할**: 앱 초기 로딩 화면
- **특징**:
  - flutter_native_splash 패키지 사용
  - 앱 초기화 중 표시
  - 브랜드 이미지/로고 표시

## 4. 온보딩 프로세스

### 4.1 신규 사용자 플로우

```
앱 실행
  ↓
Native Splash Screen
  ↓
Firebase Auth 체크
  ↓
[미인증 사용자]
  ↓
SignInView (로그인 화면)
  ↓
"처음 사용하시나요?" → TutorialView
  ↓
로그인 선택 (구글/애플/익명)
  ↓
[닉네임 미설정]
  ↓
SignupUserInput (닉네임 입력)
  ↓
MainView (메인 화면)
```

```

  ↓

  ↓
[인증된 사용자 + 닉네임 있음]
  ↓
MainView (메인 화면)
```
