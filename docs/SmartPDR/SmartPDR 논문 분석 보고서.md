# SmartPDR 논문 분석 보고서
## Smartphone-Based Pedestrian Dead Reckoning for Indoor Localization

### 논문 개요
- **저자**: Wonho Kang, Youngnam Han (KAIST)
- **게재**: IEEE SENSORS JOURNAL, VOL. 15, NO. 5, MAY 2015
- **주제**: 스마트폰 내장 센서만을 이용한 실내 보행자 추적 시스템

### 1. 연구 배경 및 목적

#### 1.1 문제 정의
- **GPS 한계**: 실내 환경에서 GPS 신호 약화로 위치 추적 불가
- **기존 방법의 문제점**:
  - Wi-Fi 기반: 사전 학습(fingerprinting) 필요, AP 설치 비용
  - 인프라 기반: 적외선, 초음파, UWB 등 고가 장비 필요
  - 지도 정보: 실내 지도가 없거나 보안상 제공 불가

#### 1.2 연구 목표
- 인프라 없이 작동하는 독립형 실내 위치 추적
- 스마트폰 내장 센서만 활용
- 실시간 보행자 추적

### 2. SmartPDR 시스템 아키텍처

#### 2.1 핵심 구성요소
1. **걸음 감지 (Step Event Detection)**
   - 가속도계 데이터 활용
   - 수직 가속도 패턴 분석
   
2. **방향 추정 (Heading Direction Estimation)**
   - 자력계 + 자이로스코프 융합
   - 상관관계 기반 선택적 활용
   
3. **보폭 추정 (Step Length Estimation)**
   - 동적 모델 적용
   - 수직 충격량 기반 계산
   
4. **위치 계산 (Location Estimation)**
   - Dead Reckoning 방식
   - 2D 평면 위치 갱신

### 3. 주요 알고리즘

#### 3.1 좌표계 변환
##### Local Coordinate System (LCS) → Global Coordinate System (GCS)
```
회전 행렬 활용:
- Roll (φ): y축 회전
- Pitch (θ): x축 회전  
- Yaw (ψ): z축 회전

최종 회전 행렬: Rt = Rψ,t × Rθ,t × Rφ,t
```

##### 변환 목적
- 스마트폰 자세 변화 보정
- 임의 방향 배치 대응
- 중력 성분 제거

#### 3.2 걸음 감지 알고리즘

##### 3단계 검증 프로세스
1. **피크 감지 (Peak Detection)**
   - 임계값: 0.5 m/s²
   - 주변 샘플과 비교
   
2. **Peak-to-Peak 검증**
   - 임계값: 1.0 m/s²
   - 피크와 골 간 차이 측정
   
3. **기울기 검증 (Slope Verification)**
   - 상승 구간 + 하강 구간 확인
   - 보행 패턴 일치 여부

##### 최종 걸음 판정
```
tstep = tpeak ∩ tpp ∩ tslope
```

#### 3.3 방향 추정 알고리즘

##### 3.3.1 자력계 기반 방향
```
hmag = atan2(-mGCS_y, mGCS_x) - hdecline
```
- 자기 편각 보정 적용
- 지구 자기장 방향 계산

##### 3.3.2 자이로스코프 기반 방향
```
hgyro = Σ(-ωGCS_z,t)
```
- 각속도 누적 적분
- 드리프트 오차 보정 필요

##### 3.3.3 하이브리드 방향 결정
**4가지 경우의 수:**

| Case | 상관관계 | 자력계 변화 | 사용 센서 |
|------|---------|------------|----------|
| I    | 낮음    | 작음       | 이전값 + 자력계 + 자이로 |
| II   | 낮음    | 큼         | 자력계 + 자이로 |
| III  | 높음    | 작음       | 이전값만 |
| IV   | 높음    | 큼         | 이전값 + 자이로 |

**임계값:**
- 상관관계: 5도
- 자력계 변화: 2도

**가중치:**
- 이전값 : 자력계 : 자이로 = 2 : 1 : 2

#### 3.4 보폭 추정 알고리즘

##### 동적 모델
```
수직 충격량 = apeak - avalley

보폭 계산:
- astep_pp < 3.230 m/s²: lk = β × ⁴√(astep_pp) + γ
- astep_pp ≥ 3.230 m/s²: lk = β × log(astep_pp) + γ

파라미터:
- 4제곱근: β=1.479, γ=-1.259
- 로그함수: β=1.131, γ=0.159
```

##### 장점
- 개인별 보행 속도 반영
- 가속/감속 상황 대응
- 정확도 향상

#### 3.5 위치 갱신
```
sk = sk-1 + lk × [sin(hk), cos(hk)]T
```
- 2D 평면 누적 계산
- 동-북 좌표계 사용

### 4. 실험 결과

- **표준편차**: 3.63도

- Case I (직진, 센서 일치): 12.11%
- Case II (회전, 센서 일치): 5.65%

- Case IV (직진, 센서 불일치): 24.23%

### 5. 기술적 특징

#### 5.1 장점
1. **독립성**
   - 인프라 불필요
   - 사전 학습 불필요
   - 지도 정보 불필요

2. **실용성**
   - 상용 스마트폰 활용
   - 실시간 처리 가능
   - 다양한 환경 적용

3. **정확도**
   - 1.35m 평균 오차
   - 복잡한 경로 추적 가능

#### 5.2 한계점
1. **누적 오차**
   - 시간 경과에 따른 오차 증가

3. **스마트폰 배치**
   - 손 떨림 영향
   - 임의 방향 배치 문제

### 7. 기술 상세 분석

#### 7.1 노이즈 처리
##### High-Pass Filter (HPF)
```
gz,t = α × gz,t-1 + (1-α) × aGCS_z,t
aHPF_t = aGCS_z,t - gz,t
α = 0.9~1.0
```

##### Low-Pass Filter (LPF)
```
aLPF_t = (1/W) × Σ(aHPF_t+i)
W = 이동 평균 윈도우 크기
```

#### 7.2 드리프트 보정
```
자이로 바이어스 보정:
ω̂i,t = ωLCS_i,t - bgyro_i

z축 투영:
ωGCS_z,t = (ω̂t · gt) / |gt|
```

#### 7.3 우도 기반 방향 시점
```
thead_k = argmin(astep_t)
        tstep_k-1 < t < tstep_k
```
- 가속도 골 지점 선택
- 실제 보행 방향 대표

### 11. 결론

SmartPDR은 스마트폰 내장 센서만으로 실내 보행자를 추적하는 실용적 시스템입니다. 인프라나 사전 학습 없이 1.35m 평균 정확도를 달성했으며, 특히 센서 융합 기반 방향 추정 알고리즘과 동적 보폭 모델이 핵심 기술입니다. 누적 오차와 센서 한계는 있지만, 독립형 실내 위치 추적 분야에서 중요한 진전을 이뤘습니다.
