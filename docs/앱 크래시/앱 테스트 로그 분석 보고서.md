  - 영향: 네이버 지도 기능 완전 마비

  2. 권한 문제

  - 블루투스 권한 누락 (114줄)
  - 위치 권한 거부 (113줄)
  - OnBackInvokedCallback 미설정 경고 반복

  3. 메모리/성능 문제

  - ImageReader_JNI 버퍼 오버플로우 경고 다수

  - 메인 스레드 과부하 (Skipped frames 경고)
  - 가비지 컬렉션 빈번 발생

  4. Google Play Services 연결 문제

  - SecurityException: Unknown calling package
  - Phenotype.API 사용 불가 (DEVELOPER_ERROR)
  - Firebase 연결 실패
