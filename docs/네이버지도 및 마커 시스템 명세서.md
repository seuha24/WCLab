# 네이버지도 및 마커 시스템 명세서

## 1. 개요
SafeLight 애플리케이션의 네이버지도 시스템은 flutter_naver_map 패키지를 기반으로 구축된 위치 기반 서비스의 핵심 컴포넌트입니다. 실시간 위치 추적, 경로 표시, 마커 관리, 다양한 지도 제어 모드를 제공하여 시각장애인의 안전한 보행을 지원합니다.

## 2. 시스템 아키텍처

### 2.1 초기화 및 설정

#### 네이버맵 SDK 초기화 (main.dart)
```dart
await NaverMapSdk.instance.initialize(
  clientId: 'pzijwnqrpi',
  onAuthFailed: (ex) {
    debugPrint("********* 네이버맵 인증오류 : $ex *********");
  },
);
```

#### 클라이언트 정보
- **Client ID**: pzijwnqrpi
- **초기화 위치**: main() 함수
- **에러 처리**: onAuthFailed 콜백

### 2.2 핵심 구성 요소

#### NaverMapView (lib/presentation/views/map_view.dart)
- **역할**: 메인 지도 화면 UI
- **특징**:
  - 실시간 위치 표시
  - 출발지/목적지 검색 입력창
  - 지도 제어 모드 토글
  - 경로 안내 시작/정지 버튼

#### NaverMapViewController (lib/presentation/controllers/map_view_controller.dart)
- **역할**: 지도 상태 및 로직 관리
- **특징**:
  - GetX 컨트롤러 패턴
  - 센서 데이터 통합
  - 경로 계산 및 안내
  - 마커/오버레이 관리

#### DestinationPickerView (lib/presentation/views/destination_picker_view.dart)
- **역할**: 목적지 선택 화면
- **특징**:
  - 중앙 고정 마커 방식
  - 카카오 역지오코딩 API 연동
  - 실시간 주소 표시

#### EntranceRegistrationView (lib/presentation/views/entrance_registration_view.dart)
- **역할**: 출입구 등록 화면
- **특징**:
  - 지도에서 위치 선택
  - 건물 정보 입력
  - 출입구 정보 저장

## 3. 지도 제어 모드

### 3.1 MapControlMode 열거형
```dart
enum MapControlMode {
  idle,  // 초기 상태
  off,   // 자유 이동 모드
  on1,   // 지도 고정, 마커만 회전
  on2,   // 지도와 마커 모두 회전
}
```

### 3.2 모드별 동작

#### idle 모드
- **용도**: 초기 위치 설정
- **동작**: 
  - 현재 위치로 카메라 이동
  - 마커 업데이트
  - 초기화 완료 후 다른 모드로 전환

#### off 모드 (기본)
- **용도**: 자유로운 지도 탐색
- **동작**:
  - 사용자가 자유롭게 지도 이동
  - 마커는 현재 위치 추적
  - 드래그 시 자동 전환

#### on1 모드
- **용도**: 지도 고정 네비게이션
- **동작**:
  - 지도는 고정 방향 유지
  - 마커만 방향에 따라 회전
  - 사용자 방향을 화살표로 표시

#### on2 모드
- **용도**: 동적 네비게이션
- **동작**:
  - 사용자 방향에 따라 지도 회전
  - 마커도 함께 회전
  - 항상 진행 방향이 위쪽

## 4. 마커 시스템

### 4.1 마커 종류

#### 현재 위치 마커
```dart
NMarker? _currentLocationMarker;
```
- **ID**: 'current_location'
- **아이콘**: 
  - GPS 신호 양호: 파란색 화살표
  - GPS 신호 불량: 회색 화살표
- **크기**: 25x25 픽셀
- **회전**: 나침반 방향에 따라 동적 회전

#### 체크포인트 마커
```dart
NMarker? _testMarker;
```
- **ID**: 'checkPoint_{index}'
- **아이콘**:
  - 경유지: 빨간색 마커 (마커3.png)
  - 일반 분기점: 초록색 마커 (마커2.png)
- **용도**: 경로상 주요 지점 표시

#### 출발지 마커
- **ID**: 'start_marker'
- **아이콘**: 기본 네이버 마커
- **색상**: 파란색

#### 목적지 마커
- **ID**: 'destination_marker'
- **아이콘**: 기본 네이버 마커
- **색상**: 빨간색

## 6. 지도 옵션 및 설정

### 6.1 NaverMapViewOptions

#### 기본 설정
```dart
NaverMapViewOptions(
  indoorEnable: true,                    // 실내 지도 활성화
  initialCameraPosition: NCameraPosition(
    target: NLatLng(37.4865, 126.8018),  // 가톨릭대학교
    zoom: 18.5,                          // 줌 레벨
    bearing: compassValue,               // 방향
    tilt: 0,                            // 기울기
  ),
  mapType: NMapType.basic,              // 지도 타입
  activeLayerGroups: [
    NLayerGroup.building,               // 건물 레이어
    NLayerGroup.transit,                // 교통 레이어
  ],
  locationButtonEnable: false,          // 위치 버튼
)
```

### 6.2 지도 타입
- **basic**: 기본 지도
- **satellite**: 위성 지도
- **hybrid**: 위성 + 도로
- **terrain**: 지형 지도

### 6.3 레이어 그룹
- **building**: 건물 정보
- **transit**: 대중교통
- **bicycle**: 자전거 도로
- **traffic**: 실시간 교통
- **cadastral**: 지적도
