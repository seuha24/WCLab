# 경로안내 기능 명세서

## 개요
SafeLight 애플리케이션의 경로안내 시스템은 시각장애인이 안전하고 정확하게 목적지까지 도착할 수 있도록 돕는 핵심 기능입니다. TMAP 보행자 API를 기반으로 경로를 탐색하고, 음성/진동 피드백으로 실시간 안내를 제공합니다. GPS와 IMU 센서를 융합하여 정확한 위치 추적과 방향 안내를 구현합니다.

## 주요 기능

### 1. 경로 탐색 시스템

#### 1.1 경로 탐색 옵션
```dart
searchOption 종류:
- "0": 추천 경로
- "4": 추천 + 대로 우선
- "10": 최단 거리
- "30": 최단 거리 + 계단 제외
```

#### 1.2 경유지 지원
- **최대 경유지**: 5개
- **경유지 형식**: passList (longitude,latitude_longitude,latitude)
- **즐겨찾기 경로**: 출발지, 목적지, 경유지 3개 저장 가능

#### 1.3 출입구 연동
- 건물 선택 시 등록된 출입구 정보 활용
- 출입구가 없으면 건물 중심점 사용
- 사용자가 등록한 출입구 우선 적용

- 네트워크 부하 감소

### 3. 경로 데이터 구조

#### 3.1 BranchInfo (분기점 정보)
```dart
class BranchInfo {
  LatLng point;           // 좌표
  String description;     // 안내 문구 ("우회전", "좌회전" 등)
  double bearingToPoint;  // 다음 지점까지 방향 (0-360도)
  bool crosswalk;        // 횡단보도 여부 (facilityType == 15)
  bool branch;           // 분기점 여부 (Point 타입)
}
```

#### 3.2 경로 구성
- **paths**: 전체 경로의 좌표 리스트 (LatLng[])
- **branchInfo**: 분기점 정보 리스트 (BranchInfo[])
- **LineString**: 직선 구간 경로
- **Point**: 회전/분기 지점

## 실시간 경로 안내

### 1. 네비게이션 타이머

#### 1.1 주기적 업데이트 (2초)
```dart
Timer.periodic(Duration(seconds: 2), (timer) {
  checkBoundary();        // 경계 이탈 확인
  indexUpdate();          // 현재 구간 업데이트
  checkStartPoint();      // 출발지 이탈 확인
  updateRemainDistance(); // 남은 거리 계산
  provideFeedback();      // 피드백 제공
});
```

#### 1.2 거리 계산
- Haversine 공식으로 구면 거리 계산
- 점-선 거리 계산으로 경로 이탈 감지
- 다음 분기점까지 남은 거리 실시간 업데이트

### 2. 방향 안내 시스템

#### 2.1 시계 방향 안내
```dart
12시: 직진
1-2시: 약간 우측
3시: 우회전
4-5시: 우측 후방
6시: 뒤로
7-8시: 좌측 후방
9시: 좌회전
10-11시: 약간 좌측
```

#### 2.2 방향 계산
- 현재 위치 → 목표 지점 방향
- 나침반 값으로 보정
- 구면 삼각법으로 정확한 각도 계산

#### 2.3 경로 정렬 확인
- 올바른 방향: ±18도 이내
- 진동 피드백: 200ms
- 경로 이탈: 100ms 진동 + 음성 안내

### 3. 경로 이탈 처리

#### 3.1 경계 범위
- **정상 범위**: 1.5m 이내
- **경고 범위**: 1.5m ~ 15m
- **재검색 범위**: 15m 이상

#### 3.2 출발지 이탈
```dart
if (distanceFromStart > 70m) {
  searchStartNewPathTime++;
  if (searchStartNewPathTime > 14) { // 30초 경과
    // 현재 위치를 새 출발지로 재검색
    loadPathData(currentLocation, destination);
    speak("출발지에서 벗어나 새로운 경로로 안내합니다.");
  }
}
```

#### 3.3 경로 이탈
```dart
if (outOfBound && searchNewPath) {
  searchNewPathTime++;
  if (searchNewPathTime >= 5) { // 10초 경과
    // 현재 위치에서 재검색
    loadPathData(currentLocation, destination);
    speak("경로를 이탈하여 새로운 경로로 안내합니다.");
  }
}
```

### 4. 음성 안내 (TTS)

#### 4.1 안내 시점
- **15m 전**: 분기점 사전 안내
- **분기점 도달**: 회전 방향 안내
- **경로 이탈**: 방향 수정 안내
- **지도 탭**: 남은 거리 안내

#### 4.2 특수 상황 안내
- **횡단보도**: "잠시 후 횡단보도입니다. 차량에 유의하세요!"
- **경광등 연동**: 횡단보도 15m 전 자동 작동
- **GPS 불량**: "GPS 정확도가 낮습니다. 출발지를 조정하세요."

### 5. 지도 표시 모드

#### 5.1 MapControlMode
```dart
enum MapControlMode {
  idle,  // 초기 상태
  off,   // 자유 이동 (기본)
  on1,   // 지도 고정, 마커만 회전
  on2,   // 지도와 마커 모두 회전
}
```

#### 5.2 마커 표시
- **파란색**: GPS 사용 중
- **빨간색**: IMU 사용 중
- **원형**: off/idle 모드
- **화살표**: on1/on2 모드

#### 5.3 경로 오버레이
- 파란색 선으로 전체 경로 표시
- 녹색 원으로 체크포인트 표시
- 줌 레벨: 18.5 (상세 표시)

## 에러 처리

### 1. API 에러
- 네트워크 오류 → 재시도
- 인증 실패 → 토스트 메시지
- 결과 없음 → "검색 결과가 없습니다"

### 2. GPS 에러
- 권한 거부 → 권한 요청 다이얼로그
- GPS 꺼짐 → 설정 이동 안내
- 정확도 낮음 → IMU 전환

### 3. 경로 에러
- 경로 없음 → 다른 옵션 제안
- 거리 초과 → "너무 먼 거리입니다"
- 경유지 초과 → "최대 5개까지 가능합니다"
