## 1. BVI 센서 융합 방식

### 1.1 핵심 특징
```
[Wi-Fi 측위] + [IMU 모션] → [칼만 필터] → [융합 위치]
```

### 1.2 장점 ✅
1. **절대 위치 보정**
   - Wi-Fi 측위로 누적 오차 제거
   - 장시간 안정적 추적 가능
   - 드리프트 자동 보정

2. **환경 강건성**
   - 자기장 간섭 시 Wi-Fi 백업
   - 다중 센서 크로스체크
   - 이상치 필터링 용이

3. **시각장애인 특화**
   - 낮은 정확도 요구사항 충족 (3-5m)
   - "접근 가능한 표지판" 개념
   - 안전 우선 설계

### 1.3 단점 ❌
1. **인프라 의존성**
   - Wi-Fi AP 필수
   - Fingerprint DB 구축 (10분/3000m²)
   - 환경 변화 시 재학습

2. **구현 복잡도**
   - 칼만 필터 튜닝 어려움
   - Q/R 행렬 최적화 필요
   - 사용자별 파라미터 다름

3. **성능 제약**
   - 업데이트 주기 느림 (700ms)
   - 배터리 소모 높음
   - Wi-Fi 스캔 지연

### 1.4 구현 난이도: ⭐⭐⭐⭐☆ (4/5)
```python
# 주요 구현 과제
- 칼만 필터 상태 방정식 설계
- Wi-Fi fingerprinting 엔진
- 노이즈 공분산 행렬 조정
- 센서 융합 파이프라인
```

## 2. SmartPDR 방식

### 2.1 핵심 특징
```
[가속도계] → [걸음 감지] → [보폭 추정]
     +                           ↓
[자력계+자이로] → [방향 추정] → [위치 갱신]
```

### 2.2 장점 ✅
1. **독립성**
   - 인프라 불필요
   - 즉시 사용 가능
   - 환경 제약 없음

2. **정확도**
   - 1.35m 평균 오차
   - 2.28° 방향 오차
   - 단기간 높은 정밀도

3. **실시간성**
   - 50ms 빠른 응답
   - 부드러운 추적
   - 낮은 지연시간

4. **효율성**
   - 중간 수준 배터리 소모
   - 경량 알고리즘
   - 스마트폰 최적화

### 2.3 단점 ❌
1. **누적 오차**
   - 시간 경과 시 증가
   - 절대 위치 상실
   - 보정 방법 없음

2. **센서 한계**
   - 자기장 간섭 민감
   - 온도 드리프트
   - MEMS 센서 노이즈

3. **개인차**
   - 보폭 캘리브레이션 필요
   - 보행 패턴 차이
   - 연령/신체별 조정

### 2.4 구현 난이도: ⭐⭐⭐☆☆ (3/5)
```python
# 주요 구현 과제
- 3단계 걸음 감지
- 4-Case 방향 결정
- 동적 보폭 모델
- 좌표계 변환
```

## 3. 방향 알고리즘 상세 비교

### 3.1 BVI 방향 처리
```python
# 헤딩 스무딩 (속도 적응적)
θₖ₊₁ = α·θₖ + (1-α)·θc

α = {
  0.3 (v < 0.5 m/s)    # 정지/회전
  0.5+0.2v (0.5-1.5)   # 일반 보행
  0.9 (v > 1.5 m/s)    # 빠른 보행
}

# 복도 매칭
if |θ - corridor| < 30°:
    θ = corridor_direction
```

**특징**:
- 단순한 스무딩
- 복도 스냅 기능
- Wi-Fi로 주기적 보정

### 3.2 SmartPDR 방향 처리
```python
# 센서 상관관계 분석
correlation = |hmag - hgyro|

# 4-Case 결정 로직
if correlation < 5° and Δmag < 2°:  # Case I
    h = 2*hprev + 1*hmag + 2*hgyro
elif correlation < 5° and Δmag ≥ 2°:  # Case II
    h = 1*hmag + 1*hgyro
elif correlation ≥ 5° and Δmag < 2°:  # Case III
    h = hprev
else:  # Case IV
    h = 2*hprev + 2*hgyro
```

**특징**:
- 정교한 센서 선택
- 상황별 가중치
- 자체 완결적

## 4. 성능 분석

### 4.1 정확도 비교

#### 단기 추적 (< 5분)
| 지표 | BVI | SmartPDR |
|------|-----|----------|
| 위치 오차 | 3-5m | 1-2m |
| 방향 오차 | 10-15° | 2-3° |
| 안정성 | 중간 | 높음 |

#### 장기 추적 (> 30분)
| 지표 | BVI | SmartPDR |
|------|-----|----------|
| 위치 오차 | 3-5m (일정) | 10m+ (누적) |
| 방향 오차 | 10-15° (일정) | 5-10° (누적) |
| 안정성 | 높음 | 낮음 |

### 4.2 환경별 성능

#### 복도 환경
- **BVI**: Wi-Fi 신호 양호, 정확도 우수
- **SmartPDR**: 직선 구간 우수, 회전 정확

#### 개방 공간 (로비, 홀)
- **BVI**: Wi-Fi 희소, 정확도 저하
- **SmartPDR**: 자유 이동, 누적 오차

#### 계단/엘리베이터
- **BVI**: 층간 Wi-Fi 전환 지연
- **SmartPDR**: 수직 이동 미지원

#### 자기장 간섭 지역
- **BVI**: Wi-Fi 백업으로 극복
- **SmartPDR**: 방향 오차 급증
