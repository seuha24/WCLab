### 3.2 칼만 필터 아키텍처

#### 필터 구조
```
상태 벡터: x̂ = [x, y]ᵀ (사용자의 로컬 좌표)

예측 단계:
x̂ₖ₊₁ = x̂ₖ + [Δt·vₖ·cos(θₖ)]
              [Δt·vₖ·sin(θₖ)]

업데이트 단계:
Wi-Fi 측위 결과로 보정
```

#### 방향 기반 모션 모델 상세

##### 상태 전이 방정식
```math
x̂ₖ₊₁ = Fₖ · x̂ₖ + Bₖ · uₖ + wₖ

여기서:
Fₖ = [1  0]  (상태 전이 행렬)
     [0  1]

Bₖ = [Δt·cos(θₖ)  0]  (제어 입력 행렬)
     [Δt·sin(θₖ)  0]

uₖ = [vₖ]  (제어 입력: 속도)
     [0]

wₖ ~ N(0, Qₖ)  (프로세스 노이즈)
```

##### 방향 예측 구현
```python
class DirectionPrediction:
    def __init__(self, dt=0.7):
        self.dt = dt  # 시간 간격 (초)
        self.last_heading = 0
        self.alpha = 0.9  # 헤딩 스무딩 파라미터
    
    def predict_position(self, current_pos, speed, heading):
        """
        방향과 속도를 이용한 위치 예측
        
        Args:
            current_pos: (x, y) 현재 위치
            speed: 현재 속도 (m/s)
            heading: 현재 방향 (라디안)
        
        Returns:
            predicted_pos: (x, y) 예측 위치
        """
        # 헤딩 스무딩 적용
        smoothed_heading = self.smooth_heading(heading)
        
        # 위치 예측
        dx = self.dt * speed * np.cos(smoothed_heading)
        dy = self.dt * speed * np.sin(smoothed_heading)
        
        predicted_pos = (
            current_pos[0] + dx,
            current_pos[1] + dy
        )
        
        return predicted_pos
    
    def smooth_heading(self, raw_heading):
        """
        헤딩값 스무딩
        """
        # 순환 각도 차이 처리
        diff = self.angle_diff(raw_heading, self.last_heading)
        smoothed = self.last_heading + (1 - self.alpha) * diff
        
        # 0-2π 범위로 정규화
        smoothed = smoothed % (2 * np.pi)
        
        self.last_heading = smoothed
        return smoothed
    
    @staticmethod
    def angle_diff(angle1, angle2):
        """
        두 각도 사이의 최소 차이 계산 (순환 고려)
        """
        diff = angle1 - angle2
        while diff > np.pi:
            diff -= 2 * np.pi
        while diff < -np.pi:
            diff += 2 * np.pi
        return diff
```

#### 주요 구성요소
1. **Motion Estimator**: 가속도계 + 자력계로 속도/방향 계산
2. **Prediction**: 모션 모델로 다음 위치 예측
3. **Update**: Wi-Fi 측위로 예측 위치 보정

### 3.3 노이즈 공분산 행렬
- **Q 행렬**: 프로세스 노이즈 (모션 모델 불확실성)
- **R 행렬**: 관측 노이즈 (Wi-Fi 측위 불확실성)
- 경험적 상수 행렬 사용

- **확률 계산**:
```
P(측정값|위치) = e^(-(RSSI_측정-RSSI_DB)²/2σ²)
```

### 4.2 PDR (Pedestrian Dead Reckoning)

#### 4.2.1 가속도계 처리
##### 신호 처리 파이프라인
1. **진폭 계산**: 
   ```
   aₖ = √(aₓ² + aᵧ² + aᵤ²)
   ```

2. **중력 제거 (High-Pass Filter)**:
   ```
   μₖ = 0.1 × aₖ + 0.9 × μₖ₋₁
   aₖᴴᴾ = aₖ - μₖ
   ```

3. **노이즈 제거 (Low-Pass Filter)**:
   - 이동 평균 필터 (5개 샘플, 100ms)

##### 이동 감지
- **임계값**: 0.3 m/s²
- **판정 기준**: 연속 5개 샘플 체크
- **정지 상태**: 임계값 이하 유지

#### 4.2.2 걸음 주파수 추정
##### FFT 기반 분석
- **샘플링 레이트**: 10Hz (최대 5Hz 걸음 감지)
- **윈도우 크기**: 2초 (20 샘플)
- **FFT 포인트**: 1024 (제로 패딩)
- **업데이트 주기**: 0.5초 (슬라이딩 윈도우)

##### 정확도 개선
- **초기 문제**: 낮은 걸음 주파수에서 부정확
- **해결책**: 
  - 스펙트럼 진폭 기반 임계값 알고리즘
  - 1.4Hz 이하에서만 피크 검색
- **개선 결과**:
  - 평균 오차: 0.11Hz
  - 최대 오차: 0.4Hz

#### 4.2.3 보폭 추정 모델
```
보폭 = (a + b × 걸음주파수 + ε) × 키
ε ~ N(0, σₛ)

실험 결과 파라미터:
(a, b, σₛ) = (0.15, 0.14, 0.044)
```

### 4.3 나침반 (자력계) - 방향 알고리즘 상세

#### 방향 측정 과제
1. **사용자 방향 vs 이동 방향**
   - 시각장애인은 지팡이로 "스캐닝"하며 이동
   - 실제 이동 방향과 다를 수 있음

2. **기기 배치 문제**
   - 주머니, 가방 등 임의 위치
   - 방향 추정 어려움

#### 헤딩 스무딩 알고리즘
실내 자기장 간섭으로 인한 노이즈를 처리하기 위해 적응적 스무딩 적용:

##### 수식
```math
θₖ₊₁ = α · θₖ + (1 - α) · θc

여기서:
- θₖ₊₁: 스무딩된 헤딩 (t+1 시점)
- θₖ: 이전 헤딩 추정값
- θc: 나침반 원시 측정값
- α: 스무딩 파라미터 (0 ≤ α ≤ 1)
```

##### 적응적 α 파라미터
사용자 속도에 따라 α값을 동적으로 조정:

```math
α = f(vₖ) = {
  0.9           if vₖ < 0.5 m/s  (정지/느린 보행)
  0.5 + 0.2·vₖ   if 0.5 ≤ vₖ < 2 m/s (일반 보행)
  0.9           if vₖ ≥ 2 m/s  (빠른 보행)
}
```

**원리**: 
- 느린 속도: 회전 가능성 높음 → 낮은 스무딩 (α ≈ 0.3-0.5)
- 빠른 속도: 직진 가능성 높음 → 높은 스무딩 (α ≈ 0.9)

#### 실내 환경 오차
- **평균 오차**: 11-13도
- **최대 오차**: 52-58도
- **표준편차**: 10-13도
- **원인**: 건물 내 금속 구조물

#### 헤딩 매칭 기법
실내 환경의 구조적 제약을 활용한 방향 보정:

```python
def heading_matching(raw_heading, corridor_directions):
    """
    복도 방향과 매칭하여 헤딩 보정
    
    Args:
        raw_heading: 원시 나침반 측정값 (도)
        corridor_directions: 가능한 복도 방향 리스트
    
    Returns:
        matched_heading: 보정된 헤딩값
    """
    min_diff = float('inf')
    matched_heading = raw_heading
    
    for corridor_dir in corridor_directions:
        # 각도 차이 계산 (순환 고려)
        diff = abs((raw_heading - corridor_dir + 180) % 360 - 180)
        
        # 30도 이내면 복도 방향으로 스냅
        if diff < 30 and diff < min_diff:
            min_diff = diff
            matched_heading = corridor_dir
    
    return matched_heading
```

## 10. 방향 알고리즘 통합 구현

### 10.1 전체 방향 시스템 아키텍처

```python
import numpy as np
from collections import deque
from typing import Tuple, List, Optional

class DirectionSystem:
    """
    BVI를 위한 통합 방향 시스템
    센서 융합을 통한 강건한 방향 추정
    """
    
    def __init__(self):
        # 칼만 필터 파라미터
        self.x = np.array([0.0, 0.0])  # 초기 위치
        self.P = np.eye(2) * 1.0  # 초기 공분산
        self.Q = np.eye(2) * 0.1  # 프로세스 노이즈
        self.R = np.eye(2) * 1.0  # 측정 노이즈
        
        # 방향 관련 파라미터
        self.heading = 0.0  # 현재 헤딩 (라디안)
        self.speed = 0.0  # 현재 속도 (m/s)
        self.alpha = 0.9  # 헤딩 스무딩 파라미터
        
        # 복도 방향 (건물별 설정)
        self.corridor_directions = [0, 90, 180, 270]  # 도
        
        # 히스토리 관리
        self.heading_history = deque(maxlen=10)
        self.speed_history = deque(maxlen=5)
    
    def update(self, compass_heading: float, 
              accelerometer_data: np.ndarray,
              wifi_position: Optional[Tuple[float, float]] = None,
              dt: float = 0.7) -> Tuple[float, float]:
        """
        센서 데이터를 융합하여 위치와 방향 업데이트
        
        Args:
            compass_heading: 나침반 측정값 (도)
            accelerometer_data: 가속도계 데이터 (x, y, z)
            wifi_position: Wi-Fi 측위 결과 (있을 경우)
            dt: 시간 간격 (초)
        
        Returns:
            (x, y): 업데이트된 위치
        """
        # 1. 속도 추정 (PDR)
        self.speed = self._estimate_speed(accelerometer_data)
        
        # 2. 방향 처리
        processed_heading = self._process_heading(compass_heading)
        
        # 3. 칼만 필터 예측 단계
        self._kalman_predict(dt)
        
        # 4. Wi-Fi 측정값이 있으면 업데이트
        if wifi_position is not None:
            self._kalman_update(wifi_position)
        
        return tuple(self.x)
    
    def _process_heading(self, compass_heading: float) -> float:
        """
        나침반 헤딩 처리 파이프라인
        
        1. 도 → 라디안 변환
        2. 헤딩 매칭 (복도 방향)
        3. 적응적 스무딩
        4. 이상치 필터링
        """
        # 도를 라디안으로 변환
        heading_rad = np.radians(compass_heading)
        
        # 복도 방향 매칭
        matched_heading = self._corridor_matching(compass_heading)
        matched_rad = np.radians(matched_heading)
        
        # 속도 기반 적응적 스무딩
        self.alpha = self._adaptive_alpha(self.speed)
        
        # 스무딩 적용
        if len(self.heading_history) > 0:
            prev_heading = self.heading_history[-1]
            diff = self._angle_difference(matched_rad, prev_heading)
            smoothed_heading = prev_heading + (1 - self.alpha) * diff
        else:
            smoothed_heading = matched_rad
        
        # 이상치 필터링
        if len(self.heading_history) >= 3:
            if self._is_outlier(smoothed_heading):
                smoothed_heading = np.mean(list(self.heading_history)[-3:])
        
        # 히스토리 업데이트
        self.heading_history.append(smoothed_heading)
        self.heading = smoothed_heading
        
        return smoothed_heading
    
    def _corridor_matching(self, heading_deg: float) -> float:
        """
        복도 방향과 매칭
        """
        min_diff = float('inf')
        matched = heading_deg
        
        for corridor in self.corridor_directions:
            diff = abs((heading_deg - corridor + 180) % 360 - 180)
            if diff < 30 and diff < min_diff:  # 30도 임계값
                min_diff = diff
                matched = corridor
        
        return matched
    
    def _adaptive_alpha(self, speed: float) -> float:
        """
        속도 기반 적응적 스무딩 파라미터
        """
        if speed < 0.5:  # 정지/느림
            return 0.3
        elif speed < 1.5:  # 일반 보행
            return 0.5 + 0.2 * speed
        else:  # 빠른 보행
            return 0.9
    
    def _kalman_predict(self, dt: float):
        """
        칼만 필터 예측 단계
        """
        # 상태 전이
        dx = dt * self.speed * np.cos(self.heading)
        dy = dt * self.speed * np.sin(self.heading)
        
        self.x = self.x + np.array([dx, dy])
        
        # 공분산 예측
        F = np.eye(2)  # 상태 전이 행렬
        self.P = F @ self.P @ F.T + self.Q
    
    def _kalman_update(self, measurement: Tuple[float, float]):
        """
        칼만 필터 업데이트 단계
        """
        z = np.array(measurement)
        
        # 혁신 (innovation)
        y = z - self.x
        
        # 혁신 공분산
        S = self.P + self.R
        
        # 칼만 이득
        K = self.P @ np.linalg.inv(S)
        
        # 상태 업데이트
        self.x = self.x + K @ y
        
        # 공분산 업데이트
        self.P = (np.eye(2) - K) @ self.P
    
    def _estimate_speed(self, accel_data: np.ndarray) -> float:
        """
        가속도계 데이터로부터 속도 추정
        (PDR 알고리즘 활용)
        """
        # 진폭 계산
        magnitude = np.linalg.norm(accel_data)
        
        # 중력 제거 (간단한 하이패스 필터)
        filtered = magnitude - 9.8
        
        # 임계값 기반 이동 감지
        if abs(filtered) > 0.3:  # 이동 중
            # FFT 기반 걸음 주파수 추정 (간략화)
            step_freq = 1.5  # Hz (예시값)
            # 보폭 모델: ls = (0.15 + 0.14 * step_freq) * height
            height = 1.7  # m (예시값)
            step_length = (0.15 + 0.14 * step_freq) * height
            speed = step_freq * step_length
        else:
            speed = 0.0
        
        self.speed_history.append(speed)
        return speed
    
    def _angle_difference(self, angle1: float, angle2: float) -> float:
        """
        순환 각도 차이 계산
        """
        diff = angle1 - angle2
        while diff > np.pi:
            diff -= 2 * np.pi
        while diff < -np.pi:
            diff += 2 * np.pi
        return diff
    
    def _is_outlier(self, heading: float, threshold: float = np.pi/4) -> bool:
        """
        헤딩 이상치 감지
        """
        if len(self.heading_history) < 3:
            return False
        
        recent_mean = np.mean(list(self.heading_history)[-3:])
        diff = abs(self._angle_difference(heading, recent_mean))
        
        return diff > threshold

# 사용 예시
```

```dart
import 'dart:math' as math;
import 'package:vector_math/vector_math.dart';

class DirectionSystem {
  // 칼만 필터 상태
  Vector2 position = Vector2.zero();
  Matrix2 covariance = Matrix2.identity();
  
  // 방향 관련
  double heading = 0.0;  // 라디안
  double speed = 0.0;    // m/s
  double alpha = 0.9;    // 스무딩 파라미터
  
  // 복도 방향 (도)
  final List<double> corridorDirections = [0, 90, 180, 270];
  
  // 히스토리
  final List<double> headingHistory = [];
  static const int maxHistorySize = 10;
  
  /// 센서 데이터 업데이트
  Vector2 update({
    required double compassHeading,  // 도
    required Vector3 accelerometer,
    Vector2? wifiPosition,
    double dt = 0.7,
  }) {
    // 1. 속도 추정
    speed = _estimateSpeed(accelerometer);
    
    // 2. 방향 처리
    heading = _processHeading(compassHeading);
    
    // 3. 칼만 필터 예측
    _kalmanPredict(dt);
    
    // 4. Wi-Fi 업데이트
    if (wifiPosition != null) {
      _kalmanUpdate(wifiPosition);
    }
    
    return position;
  }
  
  /// 헤딩 처리 파이프라인
  double _processHeading(double compassDeg) {
    // 복도 매칭
    double matched = _corridorMatching(compassDeg);
    double matchedRad = matched * (math.pi / 180);
    
    // 적응적 스무딩
    alpha = _adaptiveAlpha(speed);
    
    // 스무딩 적용
    double smoothed;
    if (headingHistory.isNotEmpty) {
      double prev = headingHistory.last;
      double diff = _angleDifference(matchedRad, prev);
      smoothed = prev + (1 - alpha) * diff;
    } else {
      smoothed = matchedRad;
    }
    
    // 히스토리 업데이트
    headingHistory.add(smoothed);
    if (headingHistory.length > maxHistorySize) {
      headingHistory.removeAt(0);
    }
    
    return smoothed;
  }
  
  /// 복도 방향 매칭
  double _corridorMatching(double headingDeg) {
    double minDiff = double.infinity;
    double matched = headingDeg;
    
    for (double corridor in corridorDirections) {
      double diff = ((headingDeg - corridor + 180) % 360 - 180).abs();
      if (diff < 30 && diff < minDiff) {
        minDiff = diff;
        matched = corridor;
      }
    }
    
    return matched;
  }
  
  /// 속도 기반 적응적 알파
  double _adaptiveAlpha(double speed) {
    if (speed < 0.5) {
      return 0.3;
    } else if (speed < 1.5) {
      return 0.5 + 0.2 * speed;
    } else {
      return 0.9;
    }
  }
  
  /// 칼만 필터 예측
  void _kalmanPredict(double dt) {
    // 위치 예측
    double dx = dt * speed * math.cos(heading);
    double dy = dt * speed * math.sin(heading);
    position += Vector2(dx, dy);
    
    // 공분산 예측 (간략화)
    covariance = covariance + Matrix2.identity() * 0.1;
  }
  
  /// 칼만 필터 업데이트
  void _kalmanUpdate(Vector2 measurement) {
    // 혁신
    Vector2 innovation = measurement - position;
    
    // 칼만 이득 (간략화)
    double gain = 0.5;
    
    // 상태 업데이트
    position += innovation * gain;
    
    // 공분산 업데이트
    covariance = covariance * (1 - gain);
  }
  
  /// 속도 추정
  double _estimateSpeed(Vector3 accel) {
    double magnitude = accel.length;
    double filtered = magnitude - 9.8;
    
    if (filtered.abs() > 0.3) {
      // 이동 중 - 간단한 모델
      double stepFreq = 1.5;  // Hz
      double height = 1.7;    // m
      double stepLength = (0.15 + 0.14 * stepFreq) * height;
      return stepFreq * stepLength;
    }
    
    return 0.0;
  }
  
  /// 순환 각도 차이
  double _angleDifference(double a1, double a2) {
    double diff = a1 - a2;
    while (diff > math.pi) diff -= 2 * math.pi;
    while (diff < -math.pi) diff += 2 * math.pi;
    return diff;
  }
}
```
