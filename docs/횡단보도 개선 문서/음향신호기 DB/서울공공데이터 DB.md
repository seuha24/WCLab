  🔗 연계 활용 방안

  1️⃣ 위치 기반 음향신호기 사전 탐색 (GPS → DB 매칭)

  현재는 BLE 스캔으로만 음향신호기를 찾지만, GPS 위치 기반으로 주변 음향신호기를 미리 표시할 수 있습니다.

  [현재 방식]
  GPS 위치 → BLE 스캔 → 15m 내 기기 발견 → 연결

  [개선 방안]
  GPS 위치 → 공공DB 검색(반경 100~500m) → 지도에 미리 표시 → 접근 시 BLE 연결

  장점:
  - 사용자가 미리 주변 횡단보도 위치 파악 가능
  - "○○ 방면 50m 앞 횡단보도" 형태의 사전 안내 제공
  - BLE 범위(15m) 밖에서도 정보 제공

  ---
  2️⃣ 횡단보도 메타 정보 보강

  현재 CrosswalkRemoteDataSource는 Firebase 없이 기본 정보만 반환합니다. 공공DB로 보강 가능:

  | 현재                          | 공공DB 연계 후        |
  |-----------------------------|------------------|
  | name: "AHG001+..." (BLE ID) | name: "충무교 횡단보도" |
  | type: SINGLE_ROAD (기본값)     | type: 연동/단일 구분   |
  | dir: null                   | dir: 연동교차로 방향 정보 |

  ---
  3️⃣ 경로 안내 연동

  네비게이션 기능과 연계하여:
  - 경로상 횡단보도 사전 안내: "300m 후 가야쇼핑 횡단보도"
  - 연동 교차로 정보 활용: 큰 교차로의 연결된 횡단보도 안내
  - 시각장애인 특화 경로 제공 (음향신호기 있는 횡단보도 우선)

  거리 계산 최적화

  // Haversine 공식 대신 간단한 근사값 사용 (한국 위도 기준)
  bool isWithinRadius(double lat1, double lng1, double lat2, double lng2, double radiusM) {
    const meterPerLat = 111000;  // 위도 1도 ≈ 111km
    const meterPerLng = 88000;   // 경도 1도 ≈ 88km (한국 기준)

    final dLat = (lat2 - lat1) * meterPerLat;
    final dLng = (lng2 - lng1) * meterPerLng;

    return (dLat * dLat + dLng * dLng) <= (radiusM * radiusM);
  }

  Python 스크립트로 미리 DB 생성:

  import sqlite3
  import csv

  # DB 생성
  conn = sqlite3.connect('signal_devices.db')
  cursor = conn.cursor()

  # 테이블 생성
  cursor.execute('''
  CREATE TABLE signal_devices (
      id INTEGER PRIMARY KEY,
      name TEXT,
      linked_id INTEGER,
      district_code INTEGER,
      address TEXT,
      longitude REAL,
      latitude REAL
  )
  ''')

  # CSV 데이터 삽입
  with open('transformed_seoul_jc_data.csv', 'r', encoding='utf-8-sig') as f:
      reader = csv.DictReader(f)
      for row in reader:
          cursor.execute('''
              INSERT INTO signal_devices VALUES (?, ?, ?, ?, ?, ?, ?)
          ''', (
              int(row['교차로번호']),
              row['교차로명'],
              int(row['연동교차로코드']) if row['연동교차로코드'] != '0' else None,
              int(row['구코드']) if row['구코드'] else None,
              row['지번'],
              float(row['경도']),
              float(row['위도'])
          ))

  conn.commit()
  conn.close()
