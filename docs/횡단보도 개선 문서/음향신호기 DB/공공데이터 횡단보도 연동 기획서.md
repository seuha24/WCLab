## 1. 개요

### 1.1 목적
서울시 공공데이터 음향신호기 DB를 활용하여 GPS 위치 기반으로 주변 횡단보도를 지도에 미리 표시하는 기능 구현

### 1.2 현재 vs 개선

| 구분 | 현재 방식 | 개선 방식 |
|------|----------|----------|
| 탐지 방법 | BLE 스캔 (15m 범위) | GPS + 공공DB (1000m 범위) |
| 사전 인지 | 불가능 | 가능 ("50m 앞 횡단보도") |
| 오프라인 | 불가능 | 가능 (로컬 DB) |
| 데이터 소스 | BLE 비콘 | 서울시 공공데이터 |

### 1.3 기대 효과
- 사용자가 미리 주변 횡단보도 위치 파악 가능
- BLE 범위(15m) 밖에서도 정보 제공
- 경로 안내 시 횡단보도 사전 안내 가능

### 5.2 Entity 설계

```dart
/// 음향신호기 엔티티
class SignalDevice extends Equatable {
  final String managementId;      // 음향신호관리번호
  final String postId;            // 지주관리번호
  final int? direction;           // 방향 (도)
  final String? manufacturer;     // 제조회사
  final int displayType;          // 표출구분
  final int deviceType;           // 종류
  final String status;            // 상태
  final double longitude;         // 경도
  final double latitude;          // 위도
}
```

### 5.3 반경 필터링 알고리즘

```dart
/// 한국 위도 기준 간이 거리 계산 (Haversine 대신 성능 최적화)
bool isWithinRadius(
  double lat1, double lng1,
  double lat2, double lng2,
  double radiusM,
) {
  const meterPerLat = 111000;  // 위도 1도 ≈ 111km
  const meterPerLng = 88000;   // 경도 1도 ≈ 88km (한국 기준)

  final dLat = (lat2 - lat1) * meterPerLat;
  final dLng = (lng2 - lng1) * meterPerLng;

  return (dLat * dLat + dLng * dLng) <= (radiusM * radiusM);
}
```

### 5.4 마커 표시 전략

| 항목 | 값 | 이유 |
|------|------|------|
| 표시 반경 | 1000m | 넓은 사전 인지 범위 |
| 예상 마커 수 | 20~60개 | 메모리/렌더링 최적화 |
| 업데이트 시점 | GPS 위치 50m 이상 변경 시 | 불필요한 연산 방지 |
| 마커 아이콘 | 주황색 원형 + 보행자 아이콘 | 직관적 인식 |

### 5.5 성능 최적화

1. **메모리 캐싱**: CSV 로드 후 메모리에 전체 데이터 캐싱
2. **간이 거리 계산**: Haversine 대신 직교 좌표계 근사값 사용
3. **마커 재사용**: 위치 변경 시 기존 마커 업데이트 (제거 후 재생성 X)
4. **디바운싱**: 잦은 위치 변경 시 마커 업데이트 제한

## 8. 기존 코드와의 관계

### 8.1 기존 Crosswalk vs 신규 SignalDevice

| 구분 | 기존 Crosswalk | 신규 SignalDevice |
|------|----------------|-------------------|
| 데이터 소스 | BLE 스캔 | 공공 CSV DB |
| 용도 | BLE 연결/제어 | 지도 마커 표시 |
| 범위 | 15m (BLE) | 1000m (GPS) |
| 엔티티 | `Crosswalk` | `SignalDevice` |
| Repository | `CrosswalkRepository` | `SignalDeviceRepository` |

### 8.2 연동 포인트

- `MapOverlayController`: 마커 추가 메서드 확장
- `NaverMapViewController`: 위치 업데이트 시 UseCase 호출
- 기존 `CrosswalkBloc`과는 독립적으로 동작
