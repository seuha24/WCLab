# 로그인 및 인증 기능 명세서

## 개요
SafeLight 애플리케이션의 로그인 및 인증 시스템은 사용자가 안전하게 서비스에 접속하고 개인화된 기능을 사용할 수 있도록 지원합니다. Firebase Auth와 자체 서버 인증을 결합한 하이브리드 방식을 채택하여 보안성과 확장성을 확보했습니다.

## 지원 로그인 방식

### 1. 소셜 로그인
#### 1.1 구글 로그인
- **OAuth 2.0 프로토콜** 사용
- Google Sign-In SDK 연동
- 이메일 및 연락처 읽기 권한 요청

#### 1.2 애플 로그인
- **Sign in with Apple** 구현
- iOS 13.0 이상 지원
- Apple ID 기반 인증

#### 1.3 익명 로그인
- Firebase Anonymous Authentication 활용
- 계정 생성 없이 즉시 서비스 이용
- 추후 소셜 계정 연결 가능

### 2. 로그인 타입 (AuthType)
```dart
enum AuthType {
  google,     // 구글 계정
  apple,      // 애플 계정
  anonymous,  // 익명 사용자
}
```

## 인증 프로세스

### 1. 로그인 플로우
```
1. 로그인 화면 (SignInView)
   ↓
2. 로그인 방식 선택 (구글/애플/익명)
   ↓
3. OAuth 인증 또는 익명 인증
   ↓
4. 서버 토큰 발급 (access/refresh)
   ↓
5. 사용자 정보 확인
   ↓
6. 닉네임 미등록 시 → 회원가입 화면 (SignupUserInput)
   닉네임 등록 시 → 메인 화면 (MainView)
```

### 2. 토큰 관리 시스템

#### 2.1 토큰 구조
```dart
class Auth {
  final String accessToken;   // API 요청용 토큰
  final String refreshToken;  // 갱신용 토큰
}
```

#### 2.2 토큰 저장
- **SharedPreferences** 활용한 로컬 저장
- 저장 키:
  - `accessToken`: 액세스 토큰
  - `refreshToken`: 리프레시 토큰
  - `authTypeToken`: 로그인 타입
  - `userName`: 사용자 닉네임
  - `serverUserId`: 서버 사용자 ID

#### 2.3 토큰 자동 갱신
- **AuthInterceptor**를 통한 자동 처리
- 401 에러 발생 시 리프레시 토큰으로 갱신
- 갱신 실패 시 자동 로그아웃

## 시스템 아키텍처

### 1. 계층 구조
```
Presentation Layer (View/Bloc)
    ↓
Domain Layer (UseCase)
    ↓
Data Layer (Repository)
    ↓
Data Source Layer (Firebase/Server API)
```

### 2. 주요 컴포넌트

#### 2.1 Presentation Layer

##### Views
- **SignInView**: 로그인 화면
  - 소셜 로그인 버튼 (구글/애플)
  - 익명 로그인 버튼
  - 튜토리얼 링크
  - Lottie 애니메이션 배경

- **SignupUserInput**: 닉네임 설정 화면
  - 닉네임 입력 필드
  - 변경하기 버튼
  - 뒤로가기 시 로그아웃 처리

##### Bloc
- **AuthBloc**: 인증 상태 관리
  - Events:
    - SignInAnonymouslyEvent
    - SignInWithGoogleEvent
    - SignInWithAppleEvent
    - SignOutAllEvent
    - PatchUserInfoEvent
    - GetUserInfoEvent
  - State (AuthState):
    - signInStatus: 로그인 상태
    - signOutStatus: 로그아웃 상태
    - patchUserInfoStatus: 정보 수정 상태
    - getUserInfoStatus: 정보 조회 상태
    - userName: 사용자 이름

#### 2.2 Domain Layer

##### UseCases

###### 로그인 관련
- **SignInAnonymously**: 익명 로그인
- **SignInWithGoogle**: 구글 로그인
- **SignInWithApple**: 애플 로그인

###### 로그아웃 관련
- **SignOutAnonymously**: 익명 로그아웃
- **SignOutWithGoogle**: 구글 로그아웃
- **SignOutWithApple**: 애플 로그아웃
- **SignOutAll**: 전체 로그아웃

###### 사용자 정보 관련
- **PatchUserInfo**: 닉네임 수정
- **GetUserInfo**: 사용자 정보 조회
- **SendGoogleOAuthTokenToServer**: 구글 토큰 서버 전송
- **SendAppleOAuthTokenToServer**: 애플 토큰 서버 전송

##### Interfaces
- **AuthUseCase**: 모든 인증 UseCase의 상위 인터페이스
- **SignIn**: 로그인 UseCase 인터페이스
- **SignOut**: 로그아웃 UseCase 인터페이스

#### 2.3 Data Layer

##### Repository
- **AuthRepository** (인터페이스)
  - `signInAnonymously()`: 익명 로그인
  - `signInWithGoogle()`: 구글 로그인
  - `signInWithApple()`: 애플 로그인
  - `signOutAll()`: 전체 로그아웃
  - `patchUserInfo()`: 사용자 정보 수정
  - `getUserInfo()`: 사용자 정보 조회

- **AuthRepositoryImpl**: Repository 구현체
  - 에러 핸들링
  - 응답 데이터 처리
  - Either 패턴 활용

##### Service
- **AuthService**: 인증 데이터 관리
  - `saveAuthData()`: 토큰 저장
  - `loadAuthData()`: 토큰 로드
  - `clearAuthData()`: 토큰 삭제
  - `saveAuthType()`: 로그인 타입 저장
  - `loadAuthType()`: 로그인 타입 로드

##### Model
- **AuthDataModel**: 인증 데이터 모델
```dart
class AuthDataModel extends Auth {
  final String? userName;  // 사용자 닉네임
  final String? id;        // 서버 사용자 ID
  
  // JSON 변환 메서드
  factory AuthDataModel.fromMap(Map<String, dynamic> map)
}
```

#### 2.4 Data Source Layer

##### RemoteDataSource
- **AuthRemoteDataSource** (인터페이스)
  - Firebase Auth 연동
  - 서버 API 통신

- **AuthRemoteDataSourceImpl**: 구현체
  - FirebaseAuth 인스턴스 관리
  - GoogleSignIn 인스턴스 관리
  - Dio를 통한 서버 통신

## API 엔드포인트

### 1. 인증 관련
- **Base URL**: `http://aws2.cuksl.xyz:3333`

#### 1.1 토큰 발급
- **구글**: `POST /auth/google/token`
- **애플**: `POST /auth/apple/token`
- **리프레시**: `POST /auth/refresh`

#### 1.2 사용자 정보
- **정보 수정**: `PATCH /user/info`
- **정보 조회**: `GET /user/me`

### 2. 요청/응답 형식

#### 2.1 로그인 응답
```json
{
  "success": true,
  "data": {
    "token": {
      "accessToken": "eyJhbG...",
      "refreshToken": "eyJhbG..."
    },
    "userName": "홍길동",
    "id": "user_12345"
  }
}
```

#### 2.2 사용자 정보 수정 요청
```json
{
  "userName": "새로운닉네임"
}
```

## HTTP 인터셉터

### 1. AuthInterceptor 기능
- **자동 토큰 삽입**: 모든 API 요청에 액세스 토큰 추가
- **토큰 갱신**: 401 에러 시 자동 갱신
- **로그아웃 처리**: 갱신 실패 시 로그아웃

### 2. 인터셉터 플로우
```
요청 전 (onRequest)
├── /auth/refresh 경로 체크 → 통과
└── 액세스 토큰 헤더 추가 → Authorization: Bearer {token}

에러 발생 (onError)
├── 401 에러 체크
├── 리프레시 토큰으로 갱신 시도
├── 성공 → 원래 요청 재시도
└── 실패 → 로그아웃 처리
```

### 1. Firebase Auth
- **익명 인증**: `signInAnonymously()`

- **애플 인증**: Sign in with Apple 연동

### 2. Firebase 설정 파일
- **iOS**: `GoogleService-Info.plist`
- **Android**: `google-services.json`

### 3. OAuth 2.0 스코프
```dart
const List<String> scopes = [
  'email',
  'https://www.googleapis.com/auth/contacts.readonly',
];
```

## 보안 고려사항

### 1. 토큰 보안
- SharedPreferences 암호화 필요 (개선 사항)
- 리프레시 토큰 안전한 저장

- Bearer 토큰 헤더 전송
- 401 에러 시 자동 갱신
