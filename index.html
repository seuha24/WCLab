SafeLight

WCL은 무선통신, 인공지능, 센서 융합 기술을 바탕으로 시각장애인이 실내외 어디서든 안전하고 독립적으로 이동할 수 있는 세상을 만들어갑니다.

  • PDR + AI 측위 — IMU 센서와 가상마커 기반 실내 위치 추정으로 GPS 음영지역을 극복합니다
  • BLE IoT 연동 — 횡단보도 음향신호기와 자동 연결하여 안전한 보행을 지원합니다
  • Device + APP 융합 내비게이션 — 보조로봇과 스마트폰의 센서 데이터를 융합하여 최적 경로를 제공합니다

연구 과제

시각장애인 안심보행 보조로봇을 위한 실내 내비게이션 플랫폼

SafeLight MaaS Platform

본 연구실은 실내 악조건 채널 환경(페이딩, GPS 음영지역)에서 시각장애인(BVI)에게 안심 내비게이션 서비스를 제공하는 PDR+AI 기반 보조로봇 플랫폼을 개발합니다. 센서 데이터와 음성/햅틱 UX, 실내외 길안내 서비스를 통합하여 끊김 없는 이동 경험을 제공하는 시각장애인 특화형 MaaS(Mobility as a Service) 플랫폼이 최종 목표입니다.

01

정보 통합

Vision + IMU + IoT + GPS + QR을 하나의 시스템으로

02

수단 통합

VoiceOver + Haptic + Sensor + 보조기기를 하나의 시스템으로

03

서비스 통합

실외 + 실내 길안내를 하나의 시스템으로

Software — SafeLight APP & MaaS Cloud

GPS-IMU 하이브리드 측위와 보행자 추측 항법(PDR)을 결합하여 음영지역에서도 연속적인 위치 추적이 가능한 크로스플랫폼 내비게이션 앱을 개발합니다. 가상마커(VM) 기반 마르코프 모델링과 QR 코드를 활용한 실내 위치 보정, DRL 에이전트를 이용한 최적 경로 계획, 공공데이터 기반 건물 출입구 DB 연계, BLE IoT 음향신호기 자동 연결 등의 핵심 기술을 통합합니다. 수집된 보행 데이터를 도시 교통망과 연계하는 MaaS 클라우드 플랫폼으로 확장하여, 출발지부터 목적지까지 끊김 없는 멀티모달 이동 경험을 제공합니다.

Flutter IMU PDR Virtual Marker DRL BLE MaaS Cloud

Hardware — Robo-Cane (보조로봇)

시분할 중첩 빔 기반 다중 초음파 센서를 탑재한 안심보행 보조로봇을 설계·제작합니다. 전방 장애물을 실시간 탐지하여 거리별 3단계 햅틱 피드백으로 사용자에게 경고하며, BLE 5.0 통신으로 앱과 50ms 주기 데이터를 교환하여 다중모달 센서 융합 내비게이션을 수행합니다. 경량화 Visual SLAM 카메라를 통해 장애물 판단·회피 및 경로 보정에 필요한 비전 데이터를 수집하고, 스마트폰 앱과의 IoT 센서 데이터 융합으로 방향 벡터 보정 및 누적 오차를 저감합니다.
